# Responsive-Travel-App
=-=-=-= Beberapa hal =-=-=-=
Tailwind V4 adalah versi Tailwind kita

Jangan lupa "npm run dev" di Terminal sebelum coding

=-=-=-= Kita menggunakan embedded icons Lucide =-=-=-=

Cek lucide.dev/icons/ -> pilih icon -> opsi ketiga, tekan anak panah ke-atas -> Copy Component Name -> gunakan "<i data-lucide="nama-icon"><i>" untuk menggunakan icon.

=-=-=-= Kita menggunakan embedded Google fonts =-=-=-=

Nama-nama icon:
font-playfair = header
font-lato = sub-head
font-nunito = paragraph
